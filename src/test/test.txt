### 4) `MockMoodEntryRepository`
U `src/main/java/hr/tvz/mindcheck/mindcheckapp/repository/MockMoodEntryRepository.java` dodaj:
```java
@Override
public MoodEntry save(MoodEntry moodEntry) {
    long nextId = moodEntries.stream()
            .mapToLong(MoodEntry::getId)
            .max()
            .orElse(0L) + 1;

    MoodEntry saved = new MoodEntry(
            nextId,
            moodEntry.getMood(),
            moodEntry.getEnergyLevel(),
            moodEntry.getStressLevel(),
            moodEntry.getNotes(),
            moodEntry.getLoggedAt() != null ? moodEntry.getLoggedAt() : LocalDateTime.now()
    );

    moodEntries.add(saved);
    return saved;
}
```

### 5) `MoodEntryController` (`@RestController` POST)
U `src/main/java/hr/tvz/mindcheck/mindcheckapp/controller/MoodEntryController.java` dodaj importe:
```java
import jakarta.validation.Valid;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
```

i metodu:
```java
@PostMapping
public ResponseEntity<MoodEntry> createMoodEntry(@Valid @RequestBody MoodEntry moodEntry) {
    MoodEntry created = moodEntryService.create(moodEntry);
    return ResponseEntity.status(201).body(created);
}
```

To je to: endpoint će biti `POST /api/moodEntries` i radi isključivo kao REST.
